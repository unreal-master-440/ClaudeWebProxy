# Запуск ClaudeWebProxy — все команды для CMD

Проверено на этой машине: `[TEST] ALL PASSED` (8 из 8), реальные ответы Claude получены.
Все команды — для **Windows CMD** (не PowerShell). Копируйте построчно.

---

## 0. Открыть CMD в папке проекта

Нажмите `Win+R`, введите `cmd`, Enter. Затем:

```cmd
cd /d C:\Users\artoy\projects\claude\ClaudeWebProxy
```

Проверка, что вы в нужном месте (должны увидеть `server.js`):

```cmd
dir /b
```

---

## 1. Проверить Node.js

```cmd
node -v
```

Нужен **v22 или новее** (в режиме браузера используется встроенный WebSocket).
Если Node нет — поставьте с https://nodejs.org и откройте CMD заново.

---

## 2. Проверить, что VPN работает как System Proxy

```cmd
powershell -NoProfile -Command "Get-NetTCPConnection -LocalPort 12334 -State Listen | Select LocalAddress,LocalPort"
```

Должна быть строка `127.0.0.1  12334`.

Если пусто — откройте Hiddify и включите **System Proxy**, потом повторите команду.

Проверить, что через прокси видно не Беларусь:

```cmd
curl.exe -s -x http://127.0.0.1:12334 "http://ip-api.com/json/?fields=country,query"
```

Ожидаемо: `{"country":"United States",...}` или другая страна. **Не** `Belarus`.

---

## 3. Проверить файл `.env`

```cmd
type .env
```

Обязательные строки должны быть такими:

```text
HOST=127.0.0.1
PORT=9656
USE_BROWSER_TRANSPORT=1
CDP_PORT=9222
HTTPS_PROXY=http://127.0.0.1:12334
NO_PROXY=127.0.0.1,localhost
```

Если чего-то нет — откройте блокнотом:

```cmd
notepad .env
```

`USE_BROWSER_TRANSPORT=1` — ключевая строка: запросы идут из вкладки браузера,
потому что Cloudflare не пускает Node напрямую.

---

## 4. Освободить порты (если что-то уже запущено)

```cmd
powershell -NoProfile -Command "Get-NetTCPConnection -LocalPort 9656 -State Listen -ErrorAction SilentlyContinue | Select -First 1 OwningProcess | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }"
```

```cmd
powershell -NoProfile -Command "Get-NetTCPConnection -LocalPort 9222 -State Listen -ErrorAction SilentlyContinue | Select -First 1 OwningProcess | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }"
```

Это закрывает только процессы на этих двух портах (прокси и его браузер).

---

## 5. ЗАПУСК — одна команда

```cmd
start-proxy.cmd
```

Или, если не хотите батник:

```cmd
node server.js
```

**Что произойдёт:**

1. В консоли появятся строки:
   ```text
   [INFO] ClaudeWebProxy started
   [INFO] Listening on http://127.0.0.1:9656
   [INFO] Browser window opened for Claude login {"url":"https://claude.ai/new","cdpPort":9222}
   [INFO] Log in to Claude in the opened browser window; requests will use that page.
   ```
2. Откроется окно Chrome с **отдельным профилем** `browser-profile\`.
3. **Войдите в Claude в этом окне** — если ещё не вошли. Профиль запоминает вход,
   поэтому это нужно один раз.
4. **Окно терминала не закрывать.** Прокси работает, пока оно открыто.

Остановка: `Ctrl+C` в окне терминала.

## 7. Проверить, что прокси жив

```cmd
curl.exe -s http://127.0.0.1:9656/health
```

Ожидаемо (одной строкой):

```json
{"status":"ok","proxy":"http://127.0.0.1:12334","version":"0.1.0","auth":{"ok":true,"mode":"browser-session","note":"session taken from the browser tab"},"models":["claude-sonnet","claude-opus","claude-haiku"],"transport":"cdp-browser"}
```

Ключевое: `"auth":{"ok":true}` и `"transport":"cdp-browser"`.

Если `"auth":{"ok":false}` — вы не вошли в окне из шага 5. Войдите и повторите.

## 9. Первый настоящий запрос

```cmd
curl.exe -s -X POST http://127.0.0.1:9656/v1/chat/completions -H "Content-Type: application/json" -d "{\"model\":\"claude-sonnet\",\"messages\":[{\"role\":\"user\",\"content\":\"Ответь одним словом: работает?\"}]}"
```

Реальный ответ с этой машины:

```json
{"id":"chatcmpl-74b8119c45d84ad0a5c9c85b","object":"chat.completion","created":1794949912,"model":"claude-sonnet","choices":[{"index":0,"message":{"role":"assistant","content":"Запуск ок"},"finish_reason":"stop"}],"usage":{"prompt_tokens":6,"completion_tokens":3,"total_tokens":9}}
```

Первый запрос может идти 10–30 секунд (вкладка прогревается). Это нормально.

---

## 10. Проверить стриминг

```cmd
curl.exe -s -N -X POST http://127.0.0.1:9656/v1/chat/completions -H "Content-Type: application/json" -d "{\"model\":\"claude-sonnet\",\"stream\":true,\"messages\":[{\"role\":\"user\",\"content\":\"Напиши 3 слова через запятую\"}]}"
```

`-N` обязателен — без него curl буферизует вывод и потока не видно.

Ожидаемо: чанки `chat.completion.chunk`, последний с `"finish_reason":"stop"`, затем:

```text
data: [DONE]
```

---

## 11. Проверить Anthropic-протокол

```cmd
curl.exe -s -N -X POST http://127.0.0.1:9656/v1/messages -H "Content-Type: application/json" -d "{\"model\":\"claude-sonnet\",\"max_tokens\":1024,\"stream\":true,\"messages\":[{\"role\":\"user\",\"content\":\"Скажи привет\"}]}"
```

Ожидаемая последовательность: `message_start` → `content_block_start` → `content_block_delta` → `content_block_stop` → `message_delta` → `message_stop`.

---

## 12. Проверить Responses API

```cmd
curl.exe -s -X POST http://127.0.0.1:9656/v1/responses -H "Content-Type: application/json" -d "{\"model\":\"claude-sonnet\",\"input\":\"Ответь: ок\"}"
```

Ожидаемо: `"object":"response"`, `"status":"completed"`.

## 13. Полный автотест одной командой

```cmd
node server.js --test
```

Результат с этой машины:

```text
  PASS  GET /health
  PASS  GET /v1/models
  PASS  POST /v1/chat/completions
  PASS  POST /v1/chat/completions stream=true — SSE + [DONE]
  PASS  POST /v1/messages
  PASS  POST /v1/messages stream=true — message_start … message_stop
  PASS  POST /v1/responses
  PASS  POST /v1/responses stream=true
[TEST] ALL PASSED
```

Важно: `--test` поднимает **свой** сервер на случайном порту, но использует тот же
браузер на 9222. Поэтому окно из шага 5 должно оставаться открытым и залогиненным.

**Open WebUI:** Admin Panel → Settings → Connections → OpenAI API:

```text

API Key:  local
```

**Codex CLI:**

```cmd
node scripts/setup_codex.js
```

**Cline / Cursor / Aider:**

```text
Provider: OpenAI Compatible
Base URL: http://127.0.0.1:9656/v1
API Key:  local
Model:    claude-sonnet
```

Ограничение: у web-эндпоинта нет tool calling, поэтому агентные сценарии
(правка файлов, вызов инструментов) работать не будут — только чат.

## Если что-то не так

| Симптом | Причина | Команда-лечение |
|---|---|---|
| `EADDRINUSE` | порт 9656 занят | шаг 4 |
| `No CDP page target on 127.0.0.1:9222` | браузер закрыт | перезапустите `start-proxy.cmd` |
| `"auth":{"ok":false}` | не вошли в окне | войдите в окно из шага 5 |
| `region_unavailable` | прокси не включён | включите System Proxy в Hiddify |
| `Just a moment…` | `USE_BROWSER_TRANSPORT=0` | поставьте `=1` в `.env` |
| `Proxy refused CONNECT` | прокси 12334 не работает | шаг 2 |
| `protocol_changed` | Claude поменял формат | `node scripts/claude_auth.js --capture` |

## Безопасность

Не коммитить и никому не передавать:

```text
claude-auth.json
browser-profile\
captures\
.env
```

Все четыре уже в `.gitignore`. `browser-profile\` содержит залогиненную сессию Claude —
это фактически пароль от аккаунта.
