Подключение Claude Code

Claude Code — агентный CLI от Anthropic. Он умеет работать с любым Anthropic-совместимым endpoint, в том числе с этим прокси.

1

Убедитесь, что прокси запущен

Окно с start.cmd должно быть открыто, а в браузере — вход в Claude. Проверка:

curl.exe http://127.0.0.1:9656/health

В ответе должно быть "status":"ok" и "auth":{"ok":true …}.

2

Установите Claude Code

Официальный установщик от Anthropic (нужен Node.js 18+):

npm install -g @anthropic-ai/claude-code

Проверка установки:

claude --version
3

Направьте Claude Code на прокси

Два способа — выберите один.

Способ А — переменные окружения (разово). Действует, пока открыто это окно CMD:

set ANTHROPIC_BASE_URL=http://127.0.0.1:9656 set ANTHROPIC_AUTH_TOKEN=local set ANTHROPIC_MODEL=claude-sonnet claude

Способ Б — настройки навсегда. Создайте файл %USERPROFILE%\.claude\settings.json:

{ "env": { "ANTHROPIC_BASE_URL": "http://127.0.0.1:9656", "ANTHROPIC_AUTH_TOKEN": "local", "ANTHROPIC_MODEL": "claude-sonnet", "ANTHROPIC_SMALL_FAST_MODEL": "claude-haiku" } }

После этого достаточно запустить claude в любой папке.

ⓘ Токен любой. Прокси не проверяет ключ — он работает через вашу сессию в браузере. Значение local нужно только потому, что Claude Code отказывается стартовать без него.
4

Какие модели указывать

Обе доступны в прокси прямо сейчас:

claude-sonnet → Sonnet 5.5, основная модель claude-haiku → Haiku 5.5, быстрая и дешёвая

Имена вроде claude-sonnet-4-5 прокси отвергнет с ошибкой unsupported_model — используйте короткие.

5

Проверьте, что связка работает

set ANTHROPIC_BASE_URL=http://127.0.0.1:9656 set ANTHROPIC_AUTH_TOKEN=local claude -p "Скажи одно слово: работает"

Ответ должен прийти от Claude через ваш браузер. В окне start.cmd появится строка Request POST /v1/messages.

! Что не заработает. Веб-эндпоинт Claude не принимает вызовы инструментов, поэтому правка файлов, запуск команд и поиск по коду из Claude Code работать не будут — придёт обычный текст. max_tokens, temperature и stop игнорируются. Это способ задавать вопросы Claude из терминала, а не полноценная замена API.
Настройки Claude Code описаны в официальной документации Anthropic. Проект не связан с Anthropic.
